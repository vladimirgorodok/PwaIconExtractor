# PwaIconExtractor (Извлечение иконок PWA)

Android-приложение для извлечения иконок по адресу PWA/веб-приложения.

## Возможности

- Ввод адреса приложения (URL) с кнопкой **Вставить** из буфера обмена.
- Извлечение иконок из:
  - `manifest.webmanifest` / `<link rel="manifest">` (`icons`);
  - `<link rel="icon">`, `<link rel="apple-touch-icon">` и похожих;
  - `<meta property="og:image">`, `<meta name="twitter:image">`;
  - тегов `<img>` на странице.
- Предпросмотр найденных изображений с выбором **всех** или **по отдельности**.
- Выбор папки сохранения через системный диалог (Storage Access Framework).
- Сохранение выбранных файлов в указанную папку.
- Отображение прогресса и подробный журнал действий (загрузка страницы, поиск ресурсов, скачивание, сохранение, ошибки).

## Как использовать

1. Введите или вставьте URL PWA/сайта (например, `https://example.app`).
2. Нажмите **Извлечь** — приложение загрузит страницу, найдёт и скачает иконки/изображения.
3. В окне предпросмотра отметьте нужные элементы (или используйте **Выбрать все**).
4. Нажмите **Выбрать папку** и укажите каталог для сохранения.
5. Нажмите **Сохранить** — выбранные файлы будут скопированы с подробным логом операций.

## Сборка

- Android Studio / Gradle, JDK 17
- `minSdk 26`, `targetSdk/compileSdk 34`
- Зависимости: Jetpack Compose, OkHttp, Coroutines, DocumentFile

Сборка из командной строки (при наличии Android SDK):

```bash
./gradlew assembleDebug
```

## Примечания

- Для доступа к сайту требуется разрешение `INTERNET`.
- Извлекаются ресурсы, доступные в HTML/manifest по указанному URL (динамически подгружаемые после выполнения JS на стороне клиента элементы могут не попасть в выдачу начального HTML).
